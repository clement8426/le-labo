# Bonus : une affiche qui se lit en 3 secondes

**Durée** : 20 minutes. **Blocs** : design system, microcopie.

Une affiche A4 n'a pas de deuxième chance : pas de verso, pas de défilement. On passe devant, on lit, ou pas.

## Le sujet

Camille, présidente d'une association de quartier à Neuchâtel, vous demande une affiche pour la **Grande Soupe d'automne**. Son message, long et plein de détails, est dans [`brief-camille.md`](brief-camille.md). Tout y est, mais tout n'a pas sa place sur l'affiche. C'est le sujet de l'exercice.

## Les étapes

1. **Lisez le message de Camille** et choisissez trois informations obligatoires : quoi, quand, où. Le reste est en option : gardez-le seulement s'il ne gêne pas la lecture des trois premières.
2. **Créez l'affiche**, format A4. Outil libre : papier, Canva, Figma, Penpot, ou une IA.
3. **Faites le test des 3 secondes** : montrez l'affiche 3 secondes à quelqu'un, cachez-la, et demandez ce qu'il a retenu. A-t-il les trois informations ?
4. **Corrigez**, puis refaites le test avec une autre personne.

## Avec l'IA : construire plutôt que générer

Une IA d'images régénère tout en pixels : le texte se déforme, le logo change, et on ne peut plus rien modifier.
Mieux : faire **construire** l'affiche par un agent relié à Penpot ou Figma (par MCP), avec de vrais textes modifiables.

```
Dans Penpot, crée une affiche A4 pour cet événement. Voici le message de l'organisatrice : [coller le message de Camille].
Fais le tri toi-même : trois informations seulement doivent se lire en 3 secondes (quoi, quand, où), le reste est secondaire ou supprimé.
Une seule information en très grand, deux tailles de texte au maximum, beaucoup de vide.
Utilise des vrais calques de texte, pas d'image générée.
```

L'IA d'images reste utile pour les ingrédients : une ambiance, une texture, un moodboard.

## C'est réussi si

- Deux personnes sur trois retiennent quoi, quand et où en 3 secondes.
- On voit tout de suite ce qu'on lit en premier, puis en deuxième.
- L'affiche ne ressemble pas à toutes les autres (rubans, ardoises, lettrage au pinceau…).
