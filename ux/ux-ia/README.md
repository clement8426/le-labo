# UX × IA : les exercices

Les exercices du cours **UX × IA** de Clément Bastien, à faire seul ou en groupe : chacun se suit pas à pas.

Le cours en ligne : diapos, démonstrations, sources et lexique sur [plateforme-cours-three.vercel.app](https://plateforme-cours-three.vercel.app/ux/ux-ia/).

## Pas de terminal : votre agent s'occupe de tout

Chaque exercice contient un **prompt à copier-coller** dans votre agent IA (Claude Code, Codex, l'application ChatGPT…).
L'agent récupère lui-même ce dépôt, ouvre le bon dossier, lance ce qu'il faut, et vous guide. Vous n'avez rien à installer à la main.

## Ce qu'il vous faut

- Un navigateur.
- Un agent IA. Les offres à environ 20 francs par mois (Claude Pro, ChatGPT Plus) incluent un agent qui peut ouvrir un site et modifier des fichiers (Claude Code, Codex).
- Les prompts du cours, un par bloc : [`prompts/six-blocs.md`](prompts/six-blocs.md).

## Avant de lancer un agent IA

1. **Donnez-lui les clés** : l'intention, la cible, le ton, les pages à regarder. Sans elles, il juge pour un utilisateur moyen qui n'existe pas.
2. **Pas de vraies données** : adresses et coordonnées fictives, toujours.
3. **Sur un site en ligne qui n'est pas le vôtre**, l'agent s'arrête avant chaque envoi (formulaire, commande, inscription) et ne contourne aucune protection anti-robots.

## Les six blocs, pour mémoire

Quatre qualités à viser, deux moyens pour y arriver.

- **Qualités** : friction (décider et atteindre sans effort), accessibilité (utilisable par toute la cible), microcopie (les petits textes qui font la vente), performance perçue (la vitesse ressentie).
- **Moyens** : le design system (la cohérence rendue réutilisable) et l'analyse comportementale (observer ce que font vraiment les gens, pour savoir par quoi commencer).
