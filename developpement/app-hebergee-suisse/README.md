# Une app web et mobile, hébergée en Suisse

**En préparation.**

Construire une application web et mobile sur votre propre serveur en Suisse : les données restent chez vous, hors de portée du Cloud Act.

Au programme :
- Supabase (base de données, comptes, fichiers) sur un serveur privé chez Infomaniak.
- Une application web et une application mobile branchées dessus.
- La sécurité, les mises à jour et les sauvegardes, faites soi-même.

Les exercices arriveront dans ce dossier.
