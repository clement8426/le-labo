# Débuter avec une IA souveraine

**En préparation.**

Utiliser l'IA sans que vos données partent aux États-Unis : un outil au choix, branché sur un modèle hébergé en Suisse ou sur votre ordinateur.

Au programme :
- Le harnais et le modèle : l'application ou l'agent que vous utilisez, et le modèle qui répond derrière.
- Abonnement, API ou modèle local : qui reçoit vos données, et sous quelle loi. Une API américaine reste soumise au Cloud Act : ce qui compte, c'est le fournisseur, pas le mode d'accès.
- Brancher un harnais ouvert sur une API hébergée en Suisse, ou sur un modèle qui tourne sur votre ordinateur.
- Ce qu'il faut en plus pour des données médicales : un contrat, le secret professionnel, une relecture humaine.

Les exercices arriveront dans ce dossier.
