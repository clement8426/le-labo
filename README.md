# Le Labo : les exercices

Les exercices des cours du **Labo**, à refaire chez vous, seul ou en groupe. En cours, ils sont montrés en démonstration ; ici, c'est vous qui les faites.

Les cours en ligne (diapos, démonstrations, sources et lexique) : [plateforme-cours-three.vercel.app](https://plateforme-cours-three.vercel.app/).

## Récupérer un exercice

- **Tout le dépôt** : bouton vert **Code**, puis **Download ZIP**.
- **Avec un agent IA** (Claude Code, Codex, l'application ChatGPT…) : chaque exercice contient un **prompt à copier-coller**. L'agent récupère le dépôt, ouvre le bon dossier et lance ce qu'il faut. Vous n'avez pas besoin du terminal.

## Les règles du Labo

1. **Uniquement des données fictives.** Les personnes, les entreprises et les documents des exercices sont inventés. N'y mettez jamais les vôtres.
2. **Sur un site qui n'est pas le vôtre**, un agent s'arrête avant chaque envoi (formulaire, commande, inscription).
3. **Relisez toujours** ce qu'une IA a produit : elle se trompe, surtout sur les noms, les dates et les chiffres.
